# NATOPS Gesture Recognition Using Multiphase Machine Learning Pipeline

## 🔍 Project Overview

This project implements a gesture classification pipeline using the **NATOPS dataset**, a collection of multivariate time-series data capturing U.S. Navy aircraft handling signals. The goal is to develop a machine learning system that can accurately identify 6 critical hand gestures using body movement data collected over time.

The project follows a **three-phase pipeline**:

1. **Data Consolidation & Preprocessing**
2. **Unsupervised Clustering**
3. **Supervised Classification**

---

## 🎯 Purpose & Motivation

Aircraft carrier flight decks are high-stakes environments where clear and accurate communication is essential. Deck crew members use standardized hand signals from the **NATOPS manual** to coordinate aircraft movement.

By automating gesture recognition using machine learning, this system aims to:

- Improve safety by reducing miscommunication
- Increase operational efficiency
- Lay groundwork for real-time gesture recognition systems

## 📦 Dataset Description

- **Source**: (https://aaltd16.irisa.fr/challenge/)

The data is generated by sensors on the hands, elbows, wrists and thumbs. The data are the x,y,z coordinates for each of the eight locations.

- **Classes**: 
  1. I have command
  2. All clear
  3. Not clear
  4. Spread wings
  5. Fold wings
  6. Lock wings

- **Features**: 24 spatial signals per time step, captured from:
  1. Hand tip left, X coordinate
  2. Hand tip left, Y coordinate
  3. Hand tip left, Z coordinate
  4. Hand tip right, X coordinate
  5. Hand tip right, Y coordinate
  6. Hand tip right, Z coordinate
  7. Elbow left, X coordinate
  8. Elbow left, Y coordinate
  9. Elbow left, Z coordinate
  10. Elbow right, X coordinate
  11. Elbow right, Y coordinate
  12. Elbow right, Z coordinate
  13. Wrist left, X coordinate
  14. Wrist left, Y coordinate
  15. Wrist left, Z coordinate
  16. Wrist right, X coordinate
  17. Wrist right, Y coordinate
  18. Wrist right, Z coordinate
  19. Thumb left, X coordinate
  20. Thumb left, Y coordinate
  21. Thumb left, Z coordinate
  22. Thumb right, X coordinate
  23. Thumb right, Y coordinate
  24. Thumb right, Z coordinate
  
- **Format**:
  - 24 `.arff` files (1 per spatial feature)
  - Each sample is recorded over **51 time steps**
  - Each time step is a 24-dimensional vector

## 🔄 Project Phases

### 📁 Phase 1: Data Preparation

**Goal**: Consolidate raw `.arff` files into a single structured CSV suitable for modeling.

- Each `.arff` file represents one spatial coordinate across all samples.
- For each gesture sample:
  - Merge all 24 features across 51 time steps
  - Assign a sample ID (`sid`) and a label (`class`)
  - Tag whether the row belongs to the training or test set (`isTest`)
- Output:
  - `phase1_output.csv` containing shape `(18360, 27)` — 360 samples × 51 time steps = 18360 rows

---

### 🤖 Phase 2: Unsupervised Clustering

**Goal**: Discover atomic motion patterns across all time steps using clustering.

- Features standardized with z-score normalization
- **KMeans clustering** (`k=6`) applied to all time-step vectors
- Each time step assigned a **cluster ID**
- For each sample (`sid`):
  - Compute the **ratio** of time steps in each cluster → 6 features per sample
- Output:
  - `phase2_output.csv` containing 360 rows, one per gesture sample, with:
    - Cluster ratio features
    - Class label
    - Test/train flag

> PCA was used to visualize the clusters in 2D space.

---

### 🧠 Phase 3: Classification

**Goal**: Train models to classify gesture samples using the cluster distribution vectors.

- Train/test split was **balanced** across all gesture classes
- Input: 6-dimensional cluster ratio vectors
- Models used:
  - **Logistic Regression** (with hyperparameter tuning)
  - **K-Nearest Neighbors**
  - **Random Forest**
  - **Multi-Layer Perceptron (MLP)**
- Evaluation:
  - Accuracy
  - Classification report (Precision, Recall, F1)
  - Confusion matrix
  - Learning curves for model diagnostics

## 📈 Model Performance

- **Best Accuracy**: ~66.7% (Logistic Regression)
- **Most Confused Classes**: Class 3 had poor recall; Class 6 was classified accurately
- **Insights**:
  - Clustering-based representation captures motion signatures well
  - More advanced temporal modeling (e.g., LSTM) may improve performance

| Model                        | Accuracy | Notable Insights                         |
|-----------------------------|----------|------------------------------------------|
| **Logistic Regression**     | **66.7%** | Best performance, especially on class 6  |
| KNN (`k=6`)                 | 56.9%    | Poor on class 3 and 5                    |
| Random Forest               | 45.8%    | Underfitting, poor generalization        |
| MLP                         | 59.7%    | Decent performance with room to improve  |

Each model generates:
- Confusion matrix plots
- Prediction CSVs
- Learning curve plots (log-loss vs training size)
